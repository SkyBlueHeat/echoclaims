# Claim Model

## Domain Records

### Claim

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Unique claim identifier (primary key) |
| `publicReference` | `String` | 8-character alphanumeric reference shown to players |
| `incidentId` | `UUID` | FK to the incident being claimed |
| `playerUuid` | `UUID` | The claiming player |
| `status` | `ClaimStatus` | Current lifecycle status |
| `source` | `ClaimSource` | How the claim was created |
| `description` | `String` | Player-provided description (max length configurable) |
| `createdAt` | `long` | Epoch millis when claim was created |
| `submittedAt` | `long` | Epoch millis when claim was submitted (0 if not submitted) |
| `cancelledAt` | `long` | Epoch millis when claim was cancelled (0 if not cancelled) |
| `version` | `int` | Optimistic concurrency version |
| `metadata` | `Map<String, String>` | Extensible key-value metadata |

### ClaimStatus

| Value | Description |
|-------|-------------|
| `DRAFT` | Initial status after creation. Player can edit or cancel. |
| `SUBMITTED` | Player has submitted the claim for review. Player can cancel. |
| `CANCELLED` | Terminal state. Claim is no longer active. |

**Active statuses** (counted as "open"): `DRAFT`, `SUBMITTED`

### ClaimSource

| Value | Description |
|-------|-------------|
| `PLAYER_COMMAND` | Created via `/ec claim create` |

### ClaimAuditEntry

| Field | Type | Description |
|-------|------|-------------|
| `id` | `UUID` | Unique audit entry identifier |
| `claimId` | `UUID` | FK to the claim |
| `actorType` | `ClaimActorType` | Who performed the action |
| `actorUuid` | `UUID` | Player UUID (null for console) |
| `action` | `ClaimAction` | What action was performed |
| `reason` | `String` | Human-readable reason |
| `recordedAt` | `long` | Epoch millis |
| `claimVersion` | `int` | Claim version at time of action |
| `metadata` | `Map<String, String>` | Extensible metadata |

### ClaimActorType

| Value | Description |
|-------|-------------|
| `PLAYER` | Action performed by a player |
| `STAFF` | Action performed by staff (future) |
| `SYSTEM` | Action performed by the system (future) |

### ClaimAction

| Value | Description |
|-------|-------------|
| `CREATED` | Claim was created |
| `SUBMITTED` | Claim was submitted for review |
| `CANCELLED` | Claim was cancelled |

## Database Schema (Migration v3 + v4)

### `claims` table

```sql
CREATE TABLE claims (
    id TEXT PRIMARY KEY,
    public_reference TEXT NOT NULL UNIQUE,
    incident_id TEXT NOT NULL,
    player_uuid TEXT NOT NULL,
    status TEXT NOT NULL DEFAULT 'DRAFT',
    source TEXT NOT NULL DEFAULT 'PLAYER_COMMAND',
    description TEXT NOT NULL DEFAULT '',
    created_at INTEGER NOT NULL,
    submitted_at INTEGER NOT NULL DEFAULT 0,
    cancelled_at INTEGER NOT NULL DEFAULT 0,
    version INTEGER NOT NULL DEFAULT 0,
    metadata TEXT NOT NULL DEFAULT '',
    FOREIGN KEY (incident_id) REFERENCES incidents(id) ON DELETE RESTRICT
)
```

### `claim_audit_entries` table

```sql
CREATE TABLE claim_audit_entries (
    id TEXT PRIMARY KEY,
    claim_id TEXT NOT NULL,
    actor_type TEXT NOT NULL,
    actor_uuid TEXT,
    action TEXT NOT NULL,
    reason TEXT NOT NULL DEFAULT '',
    recorded_at INTEGER NOT NULL,
    claim_version INTEGER NOT NULL,
    metadata TEXT NOT NULL DEFAULT '',
    FOREIGN KEY (claim_id) REFERENCES claims(id) ON DELETE RESTRICT
)
```

### Indexes

| Index | Table | Columns | Purpose |
|-------|-------|---------|---------|
| `idx_claims_player_uuid` | `claims` | `player_uuid` | Player claim lookups |
| `idx_claims_status` | `claims` | `status` | Status-based counts |
| `idx_claims_incident_id` | `claims` | `incident_id` | Open claim checks |
| `idx_claims_created_at` | `claims` | `created_at DESC` | Recent claims ordering |
| `idx_claims_active_unique` | `claims` | `incident_id, player_uuid` (partial: `status IN ('DRAFT','SUBMITTED')`) | Duplicate active claim prevention |
| `idx_claim_audit_claim_id` | `claim_audit_entries` | `claim_id` | Audit lookups by claim |
| `idx_claim_audit_recorded_at` | `claim_audit_entries` | `recorded_at DESC` | Audit ordering |

### Public Reference Strategy

- 8-character alphanumeric (A-Z, 0-9, excluding ambiguous characters)
- Enforced as `UNIQUE` at the database level
- Generated by `ClaimReferenceGenerator` with collision retry
- Never exposes the internal UUID

### Duplicate Active Claim Protection

- **Application level**: `ClaimCreationService` checks `findOpenClaimsByIncident`
  before creating a new claim
- **Database level**: Partial unique index `idx_claims_active_unique` on
  `(incident_id, player_uuid) WHERE status IN ('DRAFT', 'SUBMITTED')`
- Cancelled claims do not conflict — a player can create a new claim for the
  same incident after cancelling the previous one
- Different players can each have an active claim for the same incident

### Foreign Keys

- `claims.incident_id` → `incidents.id` (ON DELETE RESTRICT)
- `claim_audit_entries.claim_id` → `claims.id` (ON DELETE RESTRICT)
- Foreign key enforcement is enabled via `PRAGMA foreign_keys = ON`
